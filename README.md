## Sobre o curso

Este repositório reúne o material de estudo de um curso de **Estatística Básica**, ministrado pelo **Téo Me Why**. A trilha parte dos fundamentos (o que é estatística, população e amostra, tipos de variáveis) e avança por medidas resumo, gráficos, probabilidade, distribuição normal e inferência estatística.

O objetivo é consolidar a base teórica necessária para trabalhar com análise de dados.

## Por que estudar estatística?

A estatística é a base para transformar dados em informação útil. Os conceitos deste curso aparecem em análise de dados, ciência de dados, pesquisa e tomada de decisão, por exemplo ao resumir um conjunto de dados, escolher o gráfico adequado, medir incerteza ou comparar grupos.
